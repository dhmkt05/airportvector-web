01 Why logistics teams care

Pricing, hub assignment and driver hand-off all start with the same question: how far is this from the hub? AirportVector answers it inside the code.

Instant rate quotes

√(X² + Y²) is the exact ground distance to the airport. Map it to your price bands at checkout — in microseconds, offline, with no geocoding bill.

Automatic hub assignment

The first three letters are the nearest commercial airport. Route the parcel to that hub, or to a hub you map it to.

Unaddressed places

Rural homes, new estates, construction sites, farms, beaches. If it has a GPS position, it has a code — even where no street address exists.

Driver-friendly

“NW of Trichy airport, about 5 km” makes sense to a person. Drivers can sanity-check a drop before they set off.

One format, 234 countries

4,133 commercial airports anchor every point on Earth. The same code format works across borders, oceans and remote regions.

Runs on your servers

Plain maths plus a small airport file. No per-lookup fees, no dependency on a third-party service to stay online.

03 How it fits your flow

  1. CaptureCustomer shares a code — from our site, your app's “use my location” button, or typed on a form.
  2. Zone & quoteYour system reads hub + distance from the code and applies your rate card instantly.
  3. Assign & routeThe parcel goes to the hub in the code (or your mapped depot). Decode to lat/lon for turn-by-turn.
  4. DeliverThe driver sees “5.5 km NW of TRZ” plus the exact pin — a human check and a precise target.

05 Integrate in an afternoon

Reference libraries in Python and JavaScript, tested against each other on 78,000+ cases. A hosted API is available to pilot partners.

Pythonrate quote
import airportvector as av

def zone_for(code, bands=(15, 50, 150, 500)):
    km = av.distance_from_anchor_m(code) / 1000
    hub = av.parse(code).anchor
    zone = next((i + 1 for i, b in enumerate(bands) if km <= b), 5)
    return hub, round(km, 1), zone

zone_for("TRZ 55511 79566")   # ('TRZ', 5.5, 1)
